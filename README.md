```sql
CREATE TABLE categories (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL UNIQUE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE recipes (
    id INT AUTO_INCREMENT PRIMARY KEY,
    title VARCHAR(255) NOT NULL,
    category INT NOT NULL,
    ingredients TEXT,
    description TEXT,
    tags TEXT,
    steps TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (category) REFERENCES categories(id) ON DELETE CASCADE
);
```

### Задание 3: Подключение к базе данных

В файле `src/db.php` я реализовала функцию `getPDO()`, которая возвращает экземпляр PDO с настройкой на выбрасывание исключений (`PDO::ERRMODE_EXCEPTION`). 

Пример кода:

```php
function getPDO() {
    $config = require __DIR__ . '/../config/db.php';
    $dsn = "mysql:host={$config['host']};dbname={$config['dbname']};charset=utf8mb4";
    try {
        $pdo = new PDO($dsn, $config['user'], $config['password'], [
            PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
            PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
        ]);
        return $pdo;
    } catch (PDOException $e) {
        die("Ошибка подключения к базе данных: " . $e->getMessage());
    }
}
```
 Параметры подключения хранятся в `config/db.php`.

Дополнительно я **не стала использовать .env**, так как этого не требовалось.

###  Задание 4: Защита от SQL-инъекций

Для защиты от SQL-инъекций я использовала **подготовленные выражения PDO** во всех SQL-запросах. Пример:

```php
$stmt = $pdo->prepare("
    INSERT INTO recipes (title, category, ingredients, description, tags, steps)
    VALUES (:title, :category, :ingredients, :description, :tags, :steps)
");
$stmt->execute([
    ':title' => $title,
    ':category' => $category,
    ':ingredients' => $ingredients,
    ':description' => $description,
    ':tags' => $tags,
    ':steps' => $steps,
]);
```

###  Задание 5: Пагинация

В файле `templates/index.php` я реализовала пагинацию с использованием **SQL-запросов LIMIT и OFFSET**, отображая по **5 рецептов на страницу**. Пример кода:

```php
$perPage = 5;
$page = isset($_GET['page']) ? (int)$_GET['page'] : 1;
$offset = ($page - 1) * $perPage;

$stmt = $pdo->prepare("
    SELECT recipes.*, categories.name AS category_name
    FROM recipes
    JOIN categories ON recipes.category = categories.id
    ORDER BY created_at DESC
    LIMIT :limit OFFSET :offset
");
$stmt->bindValue(':limit', $perPage, PDO::PARAM_INT);
$stmt->bindValue(':offset', $offset, PDO::PARAM_INT);
$stmt->execute();
$recipes = $stmt->fetchAll();
```

Реализованы ссылки для переключения между страницами:

```

/index.php?page=2
и т.д.
```

#  Ответы на контрольные вопросы

**1️ Какие преимущества даёт использование единой точки входа в веб-приложении?**  
 Единая точка входа упрощает маршрутизацию, централизует обработку запросов, позволяет легко добавлять защиту (например, авторизацию) и упрощает масштабирование.

**2️ Какие преимущества даёт использование шаблонов?**  
 Шаблоны позволяют отделить логику приложения от отображения, делают код более чистым и поддерживаемым, а также упрощают повторное использование частей интерфейса.

**3️ Какие преимущества даёт хранение данных в базе по сравнению с хранением в файлах?**  
 База данных обеспечивает надёжность, быстрое извлечение информации, возможность сложных запросов (фильтрация, сортировка) и обеспечивает согласованность данных.

**4️ Что такое SQL-инъекция? Придумайте пример SQL-инъекции и объясните, как её предотвратить.**  
 SQL-инъекция — это атака, при которой злоумышленник вставляет вредоносный SQL-код через поля ввода.  
**Пример:**  
В поле «Название» вводится: `Тест'); DROP TABLE recipes; --`  
Если данные вставляются напрямую в SQL-запрос, это может привести к удалению таблицы.  
**Предотвращение:**  
Я использовала подготовленные выражения PDO, которые экранируют все данные, поэтому SQL-код выполняется безопасно.
